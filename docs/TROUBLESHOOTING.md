# 故障排查

## 双击启动文件后提示找不到 Python

安装 Python 3.10+，确保 `py -3 --version` 或 `python --version` 能在终端显示 Python 版本。安装时可启用 Python Launcher 或 PATH 选项。启动器不自动下载或安装软件。

## 音频引擎启动失败

先解压整个下载包，再通过「启动音乐转调.cmd」打开。确认浏览器地址以 `http://127.0.0.1:` 开头。

直接打开本地 HTML 的 `file:` 地址可能受到浏览器策略限制。本项目使用经典 Blob Worker 和内嵌 WASM 减少这类问题，但浏览器环境仍需允许 Worker 和 WebAssembly。不要关闭浏览器安全保护；受管理设备的限制需要由管理员处理。

刷新页面会清除当前音乐。可以先用「试用一段示例」测试引擎，再导入自己的文件。

## 本机地址打不开

运行 `python music_transposer_server.py --no-browser`，将打印的完整地址复制到浏览器地址栏。默认端口占用时会使用其他端口，不要固定使用旧地址。

后台服务在八小时后退出；再次启动即可。Windows 启动日志位于 `%TEMP%/pitch-room-launch.log`。提交问题前请检查日志中是否含本机路径，不要附带私人音频或凭据。

## 文件能选择，但不能解码

文件扩展名相同也可能使用不同编码。尝试普通 PCM WAV，或者使用浏览器支持的 MP3。DRM 文件、损坏文件、多于两个声道的文件不受支持。

限制为 100 MB 和 10 分钟。长音频会占用较多内存；出现内存错误时，可关闭其他占用内存的页面或选择较短片段。

## 播放无声或下载按钮不可用

载入音乐后点击播放，并检查系统音量、输出设备和浏览器标签页静音状态。转调结果需要先生成；修改半音数会使旧结果失效。

下载由浏览器完成，文件一般保存在其配置的下载目录。程序只导出 WAV，不会覆盖输入文件。

## 同样降一个半音，体积或听感不同

先核对采样率、位深、声道与时长。当前导出固定 48 kHz / 24-bit；16-bit WAV 在其他参数相同时会小约三分之一。不同转调算法还可能改变相位、瞬态和输出电平。详见 [音频说明](AUDIO.md)。
